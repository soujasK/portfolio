# Soujas Kudchadkar | Portfolio

Personal portfolio website for the Personal Portfolio Website assignment.

- **Live site:** https://soujask.github.io/portfolio/
- **Stack:** plain HTML, CSS and JavaScript in a single `index.html`. No site builder and no template.
- **Sections:** About, Projects (AuditLane, Smoulder), Skills, Contact.
- **Responsive:** laptop, tablet and phone layouts (checked down to 320px wide).

## Credits

- [GSAP](https://gsap.com/) with ScrollTrigger (loaded from cdnjs) for scroll and intro animations.
- Fonts from Google Fonts: [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif), [Inter Tight](https://fonts.google.com/specimen/Inter+Tight) and [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono).
- Design, layout, copy and graphics are my own. I used Claude (an AI coding assistant) to help write and fix the code, as the assignment allows.

## Run locally

Open `index.html` in a browser. It needs an internet connection for the fonts and GSAP.

## Deploy

Settings → Pages → Deploy from branch → `main` / root.
